# Product

## Register

product

## Platform

web

## Users

University & College Students across engineering, design, and computer science departments looking for hackathon teammates, research collaborators, and side-project partners.

## Product Purpose

Project Finder connects university students with compatible teammates based on skills, department, availability, and project interests. It streamlines project recruitment, application reviews, campus event discovery, and team invitations.

## Positioning

The definitive campus collaboration network that transforms student ideas into high-performing project teams with instant zero-friction matching.

## Brand Personality

Clean, Modern, Collaborative, Fast, Trustworthy.

## Anti-references

- Over-decorated SaaS cliches (gradient text, arbitrary floating glass cards)
- Cluttered, noisy social media feeds with generic stock imagery
- Unresponsive desktop-only admin grids that break on mobile devices

## Design Principles

1. **Task-Focused Density**: Keep user flow uninterrupted with high information density, clean typography, and zero decorative noise.
2. **Speed & Immediate Feedback**: Every action (bookmarking, applying, marking completed, status filtering) responds instantly with optimistic UI feedback.
3. **Earned Familiarity**: Utilize standardized component patterns (AppShell navigation, semantic badges, modal overlays) so the tool feels intuitive from day one.
4. **Accessible by Default**: Maintain high contrast ratios, distinct dark mode semantics, and fluid responsive behavior across desktop and mobile viewports.

## Accessibility & Inclusion

Targeting WCAG 2.1 AA compliance with support for prefers-reduced-motion, high-contrast dark mode, clear focus rings, and touch-friendly mobile affordances (≥ 44px targets).
